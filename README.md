# <p align="center">Kangaroo Kalamity</p>

## 🦘 Sobre el proyecto

**Kangaroo Kalamity** es un juego de plataformas de scroll vertical inspirado principalmente en *Jump King* y *Super Meat Boy*.

La premisa es simple: debes ascender hasta alcanzar la meta de cada nivel evitando enemigos y obstáculos. El desplazamiento está limitado exclusivamente a saltos, por lo que tendrás que combinar la potencia del salto —modulable según el tiempo que mantengas pulsado el botón— con el movimiento lateral para superar cada desafío.

Este proyecto nació como mi **Proyecto de Fin de Ciclo**, convirtiéndose en mi primera experiencia dentro del desarrollo de videojuegos.

Tras aproximadamente tres meses de desarrollo, diseñé, dibujé y programé esta demo jugable compuesta por tres niveles.

---

## ✨ Características

- Plataformas de scroll vertical.
- Sistema de salto con potencia variable.
- Inspiración en juegos de precisión y dificultad elevada.
- Tres niveles completamente jugables.
- Diseño, arte y programación realizados íntegramente por un único desarrollador.

## 🚀 Cómo ejecutar el juego

1. Descarga el archivo `KangarooKalamity.zip`.
2. Descomprime su contenido.
3. Ejecuta `KangarooKalamity.exe` (icono del canguro).

No requiere instalación.

## ⚠️ Advertencias

### Windows SmartScreen

En algunos equipos Windows puede identificar el ejecutable como una aplicación desconocida.

Esto ocurre porque el ejecutable no dispone de un certificado de firma digital y es habitual en proyectos independientes. Si aparece esta advertencia, puedes seleccionar **"Más información"** y posteriormente **"Ejecutar de todas formas"**.

### Resolución recomendada

El juego ha sido diseñado para pantallas con relación de aspecto **16:9**.

En monitores **4:3** u otros formatos poco comunes podrían aparecer problemas de visualización o escalado.
